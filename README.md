# Meus Estudos de SQL e Banco de Dados 🚀

Repositório dedicado ao aprendizado prático de SQL, modelagem e administração de bancos de dados relacionais (PostgreSQL/MySQL) rodando no Linux Mint.

## 📝 Minha Estrutura de Anotações Pessoais

Para cada novo comando ou conceito aprendido, sigo este modelo de fixação:

1. **Conceito (O que é e por que importa):** Explicação simples da utilidade real.
2. **A Planta Baixa (O código-padrão):** O bloco de código SQL limpo e comentado.
3. **A Pegadinha:** Cuidados específicos e detalhes de performance/segurança.
4. **Meu Laboratório:** Espaço para colar os testes práticos rodados no DBeaver.
